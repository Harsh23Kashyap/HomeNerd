Nerd family homepage - local review copy

Open index.html in Chrome. Keep index.html, people.html, styles.css and script.js together in the same folder. It works from file:// and needs no server or image downloads. Illustrations are inline SVGs. Use People in the top navigation for the separate credits page.

This is the seven-project review design, not a deployment of nerdmama.org. Six project cards now open a verified external site in a new tab. PatentNerd remains non-clickable until its URL is confirmed. People credits now include only verified project connections; several possible contributors are omitted where attribution is unverified. Source details and remaining limitations are below.

This updated copy adds gentle, looping motion to all seven project illustrations. On a desktop pointer, hovering also lifts a card and scales its artwork; on touch screens, the looping artwork remains visible. The system's reduced-motion preference disables those effects.

Card update: on desktop, hover a card to read the short explanation and sample question. Clicking either face opens that project site in a new tab. On touch screens, tapping a linked card opens its site directly rather than showing the back. Keyboard users can focus a linked card and press Enter or Space to open its site. PatentNerd stays unlinked until its address is confirmed. Reduced-motion preference turns off the flip transition.

The reverse-side descriptions and example questions are review copy, not claims that every named service currently supports those exact prompts. Please verify project descriptions and People credits before public release.
